### 1. Cài NVM
Bước 1: Cài NVM
- `brew install nvm`
- Nếu bạn chưa có Homebrew, cài đặt qua lệnh sau: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)"`

Bước 2: Đưa nvm vào hệ thống
`source $(brew --prefix nvm)/nvm.sh`

Bước 3: Kiểm tra cài đặt thành công
`nvm --version`

### 2. Cài NodeJS
Chạy lệnh ở terminal
- `nvm install v22.9.0`
- `nvm use v22.9.0`
